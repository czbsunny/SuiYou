# Stewardship 页面复刻计划

## 项目概述

根据设计文件分析，需要复刻5个页面并按照以下目录结构组织：

| 设计文件 | 页面功能 | 目标目录 |
|---------|---------|---------|
| `_1/code.html` | 预算管理页面 | `bill/budget.html` |
| `_2/code.html` | 记账页面 | `bill/record.html` |
| `_5/code.html` | 收支明细页面 | `bill/detail.html` |
| `_3/code.html` | 月度报告页面 | `report/monthly.html` |
| `_4/code.html` | 存钱计划页面 | `goal/savings.html` |

## 目录结构

```
app/
├── bill/           # 账单相关页面
│   ├── budget.html     # 预算管理
│   ├── record.html     # 记账录入
│   └── detail.html     # 收支明细
├── report/         # 报告相关页面
│   └── monthly.html    # 月度报告
└── goal/           # 目标相关页面
    └── savings.html    # 存钱计划
```

## 技术栈

- **框架**: 原生 HTML + CSS + JavaScript
- **CSS 框架**: Tailwind CSS 3.x
- **图标库**: Material Symbols Outlined
- **字体**: Plus Jakarta Sans + JetBrains Mono

## 页面功能分析

### 1. 预算管理 (`bill/budget.html`)
- 环形进度图显示预算使用情况
- 支出分类列表（餐饮、交通、购物、居住）
- 预算进度条显示
- 底部导航栏

### 2. 记账页面 (`bill/record.html`)
- 支出/收入切换器（滑动选择器）
- 分类选择（一级分类 + 二级子分类）
- 数字键盘输入金额
- 日期、账户、备注信息

### 3. 收支明细 (`bill/detail.html`)
- 时间分组显示交易记录
- 支出/收入金额汇总
- 交易项目列表（图标、名称、时间、金额）
- 底部导航栏

### 4. 月度报告 (`report/monthly.html`)
- 收支概览卡片
- 支出环形图
- 收入/支出进度条
- 支出 Top 5 列表
- 投资收益模块
- 资产分布卡片

### 5. 存钱计划 (`goal/savings.html`)
- 储蓄总额显示
- 智能建议卡片
- 蓄水池计划列表（进度条、目标金额）
- 小猪存钱罐成就卡片
- 理财周报入口

## 实施步骤

### 步骤 1: 创建目录结构
- 创建 `bill/`、`report/`、`goal/` 目录

### 步骤 2: 复制并整理页面文件
- 将设计文件按目录结构复制并重命名
- 确保所有资源引用正确

### 步骤 3: 统一资源引用
- 确保所有页面使用相同的 Tailwind CSS CDN
- 确保 Material Symbols 图标正确加载
- 确保字体引用一致

### 步骤 4: 页面间导航链接
- 更新底部导航栏链接
- 确保页面间可以正确跳转

### 步骤 5: 验证页面功能
- 检查所有交互功能正常工作
- 检查响应式布局

## 注意事项

1. **资源引用**: 确保所有外部资源（图标、字体、CDN）引用正确
2. **交互功能**: 保留原设计的微交互动画（进度环、数字键盘、切换器等）
3. **视觉一致性**: 保持所有页面的设计风格统一
4. **移动端适配**: 确保所有页面在移动端正确显示

## 风险评估

| 风险 | 描述 | 缓解措施 |
|-----|------|---------|
| 外部资源依赖 | 依赖 Google Fonts 和 CDN | 考虑本地缓存或使用稳定的 CDN |
| 兼容性问题 | 某些 CSS 属性可能不兼容旧浏览器 | 使用标准 CSS 属性，避免实验性特性 |
| 响应式适配 | 不同设备屏幕尺寸适配 | 使用 Tailwind 的响应式工具类 |
